# FUTURE_HYPOTHESIS.md — トレンド内の短期の伸びきり回避（将来の別プロジェクト向け仮説）

2026-08-30、stockbotTOM v8（順張り押し目プロジェクト）の終了（`CLOSING.md`）に伴い、
DESIGN.md §13.1（2026-08-29 追記）からそのまま切り出した。**このプロジェクトでは
検定していない。** 本プロジェクトの設計窓・内部確認窓・頑健性窓・ホールドアウトの
いずれとも重ならないデータに対して、独立に事前登録した別プロジェクトとして
テストする場合のための記録。

## 由来

設計窓・h=3 での F1〜F14 再チェック（DESIGN.md §10.7）で、依然として末端分位が
負のまま残った 4 条件（F4: d3_dev5 上端、F10: d2_rs60 上端、F11: d2_rs120 上端、
F12: d2_rsline_pos 上端）はすべて「伸びきったもの（短期乖離・相対力が過大なもの）
を買わない」という共通の形をしている。押し目の形状（深さ・位置・戻り率・期間、
F1・F3・F5・F6・F9・F13・F14）と方向系（F2・F7・F8）は h=3 でペイオフを持たず、
残るのは短期的な伸びきり回避（短期リバーサル）だけという読み方ができる。
RESEARCH.md §1.2（日本の短期リバーサル）・§1.3 の時間軸と整合する。

## 仮説

「順張り押し目ではなく、トレンド内の短期の伸びきり回避」——トレンド条件
（G1〜G3 相当）を満たした銘柄群の中で、短期的に伸びきった状態（F4・F10・F11・
F12 が捉える方向）を避けることに、押し目の形状そのものとは独立したペイオフが
あるという仮説。

## テストする場合の条件

- 本プロジェクト（順張り押し目、V1/V2/V3・DESIGN.md §12 の構成）の一部としては
  行わない（新規検定であり、§10.3 の見直し1回は消費済みのため）
- 実際にテストする場合は、本プロジェクトの設計窓・内部確認窓・頑健性窓・
  ホールドアウトのいずれとも重ならない期間（または将来のデータ）に対して、
  独立に事前登録した別プロジェクトとして行う
- 対象条件: F4（d3_dev5 上端）・F10（d2_rs60 上端）・F11（d2_rs120 上端）・
  F12（d2_rsline_pos 上端）。閾値・向きの具体値は DESIGN.md §6.1 の表を参照
  （ただしそこでの向きは h=10 由来であり、この仮説自体は再検証が前提）

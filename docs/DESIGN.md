## 0. 用語と記法

- T: 評価日（営業日）。すべての量は T の引けまでのデータで計算する
- k: スイング確定ラグ（本数）。既定 3
- SMA_n: 終値の単純移動平均。使う n は 5 / 25 / 75 / 200 のみ
- ATR: Wilder の 14 日 ATR。TR = max(H−L, |H−C_prev|, |L−C_prev|)
- 週足: 金曜終わりの週（W-FRI）に集約。T を含む週は未確定として使わない
- ↑ 大きいほど良い、↓ 小さいほど良い、∩ 適正帯 [a, b] がある
- 「銘柄×日」: 1 銘柄の 1 評価日を 1 観測とする

## 1. 日次の流れ

1. ユニバース（M1）: 株式のみ、20 日平均売買代金 ≥ 2 億円、株価 ≥ 200 円、履歴 ≥ 250 本、最終足が 7 日以内、分割疑いなし
2. ゲート G0〜G3（§2）
3. スイング検出（§3）→ 押し目構造と状態（§4）。状態が 形成中 / 反発開始 / ブレイク の銘柄だけ先へ
4. 特徴量 D1〜D8（§5）
5. 正規化と合成（§6）、テンプレート適合度（§7）
6. 順位付け・多様性・内訳（§8）
7. 全採点銘柄の特徴量とスコアを日付別に保存（前向き検証用）

## 2. ゲート（ハード条件・4 つだけ）

| ID | 条件 | 意図 |
|---|---|---|
| G0 | ユニバース通過、かつ T から保有上限（15 営業日）以内に決算発表が無い（予定日が取れない場合はこの条件を省略し、その旨を出力に明記） | 執行可能性・決算ギャップ回避 |

## 3. スイング検出（fractal・確定ラグ付き）

- スイング高値: High[i] ≥ max(High[i−k..i−1]) かつ High[i] > max(High[i+1..i+k])
- スイング安値: Low[i] ≤ min(Low[i−k..i−1]) かつ Low[i] < min(Low[i+1..i+k])
- 確定: インデックス i のスイングは i+k の引けで確定する。T で使えるのは i ≤ T−k のもののみ
- 交互化: 時間順に走査し、高値が連続したら高い方を、安値が連続したら低い方を残す（後から来た方が極端なら置き換える）
  - 交互化は、T 時点で確定済み（i ≤ T−k）の生スイング集合に対して毎回適用する。T が進むと
    末尾の1要素が置き換わることがあるが、これは新たに確定した情報による更新であり未来参照
    ではない。置換は末尾要素にのみ起こる（i1 < i2 の間にある反対側のスイングは i2 より先に
    確定するため）
  - 同値の扱い: 生検出では右側が厳密不等号のため、k 本以内の同値高値（安値）は後の方が
    スイングになる。交互化での同値は先に来た方を残す（置換は厳密に極端な場合のみ）
- ZigZag は使わない（確定ラグが不定で未来参照になる）

実装上の必須テスト: §11 参照（生スイング検出と交互化を別々に検査する）。

## 4. 押し目の構造と状態

### 4.1 構造（T 時点）

- H0: 確定済みスイング高値のうち最新（インデックス h0 ≤ T−k）。かつ H0 は直前 60 本の最高値（H0.high = max(High[h0−60..h0]））であること
- L0: h0 より前の直近の確定スイング安値（交互化後なので必ず存在する想定。無ければ構造なし）
- 上昇脚: leg = H0.high − L0.low、leg_bars = h0 − l0 ≥ 3
- 押し目区間: h0+1 .. T、日数 d = T − h0
- 押し安値: Lp = min(Low[h0+1..T])、その位置 lp
- 戻り高値 R: lp < T−1 のとき R = max(High[lp+1..T−1])。無ければ欠損
- 基本量（すべて連続値）
  - depth_pct = (H0.high − Lp) / H0.high
  - depth_atr = (H0.high − Lp) / ATR[h0]
  - retrace = (H0.high − Lp) / leg
  - position = (Close[T] − Lp) / (H0.high − Lp)
  - dev5 = Close[T] / SMA5[T] − 1（5 日線乖離率。西村ルールの核）

### 4.2 押し目であるための条件

- 2 ≤ d ≤ 25
- Lp > L0.low（前の押し安値を割っていない）
- max(High[h0+1..T]) < H0.high（H0 未更新）
- depth_pct ≤ 0.25
- Close[T] ≥ SMA200[T]（G2 と同じ。失効判定にも使う）

### 4.3 反発トリガー（日 t で評価）

- trig_a: Close[t] > High[t−1] かつ Close[t] > SMA5[t]
- trig_b: SMA5[t] > SMA5[t−1] かつ SMA5[t−1] ≤ SMA5[t−2] かつ Close[t] > SMA5[t]（5 日線の上向き転換）
- トリガー発火 = trig_a または trig_b

### 4.4 状態（毎日ちょうど一つ）

| 状態 | 定義 |
|---|---|
| 完了 | High[T] > H0.high（または Close[T] > H0.high）。候補から外す。検証では成功として記録 |
| 失効 | 4.2 のいずれかを満たさない（Lp ≤ L0.low、depth_pct > 0.25、d > 25、Close < SMA200） |
| ブレイク | 4.2 を満たし、R が存在し、Close[T] > R |
| 反発開始 | 4.2 を満たし、t_trig ∈ {T−2, T−1, T} にトリガー発火があり、lp ≤ t_trig（トリガー後に安値更新なし） |
| 形成中 | 4.2 を満たし、上記のいずれでもない |

- 浅押し: depth_pct < 0.03 は状態を維持するが「候補」に出さない（監視のみ）。リサーチ A で 0〜3% 押しの期待値がほぼゼロだったため
- 深押し: depth_pct > 0.10 は §5 D3 の「悪材料混入フラグ」が立っていない場合のみ候補に出す

表示用の参照値: 押し安値 = Lp（構造ストップ参考）、ブレイク参照 = R（無ければ H0.high）

## 6. 正規化と合成

### 6.1 基準集合（プール）
その日のゲート通過かつ押し目状態（形成中/反発開始/ブレイク）の銘柄だけでは母集団が日によって大きく変わるため、
**直近 20 営業日（T を含む）のゲート通過・押し目状態の銘柄×日をプール**し、これに対する位置で正規化する。

### 6.2 特徴量の変換
- ↑: プール内百分位（0〜1）。↓: 1 − 百分位
- ∩（帯 [a, b]）: 帯の内側は 1、外側は帯幅 w = b − a だけ離れた所で 0 になる線形減衰。score = clip(1 − dist/w, 0, 1)
- 二値: そのまま 0/1（d3_bad_news は 1 − 値、d4_climax は L1 で方向を決めるまで次元合成に入れない）
- 欠損: 0.5

### 6.3 次元スコアと総合
- 次元スコア = その次元の特徴量スコアの単純平均（0〜1）
- 状態別に使う次元: 形成中 = {D1, D2, D3, D4, D5, D7}、反発開始/ブレイク = {D1〜D7}
- 総合 = 使う次元の平均 × 100（0〜100）
- 事前登録する変種（この 3 つ以外は作らない）
  - V1 等加重
  - V2 D3 を 2 倍
  - V3 出来高ゲート: d4_pb_ratio > 1.0 の銘柄は候補に出さず監視のみ。重みは等加重

## 7. テンプレート適合度（d3_template）

- 窓: l0 .. T。横軸は時間を 0〜1 に正規化し、境界 a = leg_bars/(leg_bars + d) で上昇脚と押し目を分ける。縦軸 y = (Close − L0.low)/leg（L0 が 0、H0 が 1）
- 10×10 格子: 横は時間 10 等分、縦は y を −0.2〜1.2 の 10 等分（幅 0.14）。各セルに終値の滞在比率 P[i][j]（列ごとに合計 1）
- 適合度 = Σ W∘P を W の正の総和で割った値（0〜1 に丸める）
- W の初期値（実装は行列定数として置き、テストで「理想経路 > 崩れた経路」を確認する）
  - 上昇脚の列（0〜a）: 左下から右上に向かう対角経路のセルに +1、その上下隣接に +0.5
  - 押し目の列（a〜1）: y=1 から y=0.6〜0.67 へ緩やかに下がり、最後の 2 列は水平、の経路に +1、隣接 +0.5
  - y < 0（L0 割れ）の全セル −1
  - 押し目前半の列で y > 1.0 のセル −0.5
  - その他 0
- 出来高テンプレート: 価格と同じ 10×10 格子（横軸の区切り a も同じ）を使う。縦軸は
  v = Vol[t] / mean(Vol[l0..h0])（上昇脚の平均出来高で正規化した相対出来高）を 0〜3 の
  10 等分（1 行の幅 0.3、3 を超える値は最上段に丸める）。セルの滞在比率 P は価格と同じく
  列ごとに合計 1 とする。
  - 理想経路 W_vol（実装は行列定数として置く）
    - 上昇脚の列（0〜a）: v = 1.0〜1.4 の帯（行 3〜4）に +1、その上下隣接（行 2、行 5）に +0.5
    - 押し目の列（a〜1）のうち最後の 1 列を除く: v = 0.5〜0.8 の帯（行 1〜2）に +1、
      隣接（行 0、行 3）に +0.5
    - 押し目の最後の 1 列（再上昇の出来高増を許容）: 加点も減点もしない（全セル 0）
    - 押し目の列（最後の 1 列を除く）で v > 1.5（行 5 以上）のセルに −1
      （押し目で出来高が増えるのは分配の兆候。RESEARCH.md §3、Bulkowski のフラッグ 74〜77%）
    - その他 0
  - 適合度の計算は価格と同じ（Σ(W_vol∘P) を W_vol の正の総和で割り、0〜1 に丸める）
  - 数値の根拠: 上昇脚の 1.0〜1.4 は「脚の平均以上」、押し目の 0.5〜0.8 は RESEARCH.md の
    出来高ドライアップ（押し目中の出来高が脚より明確に少ない）を §5 の d4_pb_ratio（↓方向）
    と整合する水準に置いたもの。これらは §12 の事前登録パラメータに準じる扱いとし、L1 の
    結果でのみ改訂する
  - d3_template = (価格の適合度 + 出来高の適合度) / 2
- 校正: 候補提示→判定（良/普通/悪、40〜60 枚）の結果で、良が集中するセルを +0.25、悪が集中するセルを −0.25（1 回の校正で各セル ±0.25 まで）。校正前後で L1 の IC が下がれば戻す

## 8. 順位付け・多様性・表示

### 8.1 地合いゲージ（順位には使わない）
- 指数（TOPIX、取れなければ日経 225）について: Close > SMA25 / > SMA75 / > SMA200 / SMA75 上向き（15 日前比）の 4 点
- ブレス: breadth_75 ≥ 0.5 / breadth_200 ≥ 0.5 の 2 点
- 6 点中 5〜6 = 強、3〜4 = 中、0〜2 = 弱。検証では 3 段階で集計し、運用では表示のみ

### 8.2 順位付け
- 候補 = 反発開始・ブレイク状態、浅押し除外、V3 では出来高ゲート通過。総合スコア降順に上位 N=10
- 監視 = 形成中状態の上位 N=10
- 同じ 33 業種は候補上位 10 に最大 3
- 60 日リターンの相関 > 0.8 の組はスコアの高い方だけ残し、もう一方に「同テーマ」を付けて次点へ
- 絶対的な足切り点は置かない。「本日の最高スコア / 20 日中央値」と地合いゲージを先頭に表示
- 連続点灯日数を表示。スコアの平滑化はしない

### 8.3 カードの内訳（既存デザインの 3 ボックス＋右欄に対応）
- 左: 状態、depth_pct と depth_atr、d、着地 MA
- 中: Lp（押し安値）、R または H0（ブレイク参照）、position
- 右: 次元スコアの棒、d4_pb_ratio、earnings_days、20 日平均売買代金
- 一言: 貢献上位 2 次元と最弱 1 次元の自動文（例「トレンド・収縮が強い。弱点は出来高」）

## 9. ラベル（検証用）

- エントリー: Open[T+1]。h ∈ {3, 5, 10, 15, 20, 30}
- 超過リターン: r_h = ln(Close[T+h]/Open[T+1]) − ユニバース等加重の同じ量
- 成功/失敗/未決（N=15 主、10 と 20 を感度）: T+1 から T+N の各日で、High > H0.high なら成功、Low < Lp なら失敗。同日に両方なら失敗（保守的）。N 日以内にどちらも無ければ未決
- MFE = (max(High[T+1..T+N]) − Open[T+1])/ATR[T]、MAE = (Open[T+1] − min(Low[T+1..T+N]))/ATR[T]
- リサーチ A の知見: 深さは勝率でなくペイオフに効く。評価は成功率より超過リターンと MFE/MAE を主にする

## 11. ルックアヘッドの機械的検査（必須テスト）

「全期間で計算して T 行を取り出す」とは、各 T について T までのデータで計算する
（ローリング）ことを指す。一括計算して行を取り出すことではない。

- 再計算一致: 系列を T で切って計算した特徴量 = 全期間で計算して T 行を取り出した特徴量。全特徴量・複数 T で完全一致（浮動小数の許容 1e-9）
- スイング（生検出、交互化前）: 「T で切った系列の検出結果」＝「全期間の検出結果を i ≤ T−k で絞ったもの」。右端の未確定バー（i > T−k）をスイングとして扱わないこと
- スイング（交互化）: 「T で切った系列で生検出→交互化した結果」＝「T−1 時点の交互化結果に、T で新たに確定した生スイングを時間順に逐次適用した結果」。逐次更新と全再計算の一致を複数 T で確認する
- 週足: T を含む週の足が使われていないこと
- ラベル: T+1 以降のデータだけを使い、T 以前の行を変えても値が変わらないこと

## 13. リサーチ A の反映メモ

- トレンド条件の有無が勝率差の最大要因（単純 GC 35% vs トレンド内押し目 63%）→ G1〜G3 は緩めない

- 「浅く止まる」（押し安値・前安値を割らない）が成功の定量マーカー → 4.2 の Lp > L0、d3_hl_dist
- フィボナッチ固定水準・出来高 40% 増の固定閾値・米国パターンの勝率は採用しない

- 出典の信頼度: 西村（投資助言業者の自社検証、査読なし）、Bulkowski（米国・完璧トレード前提）。数値は直接使わず再現対象・方向の根拠として使う
